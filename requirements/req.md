## REQ01: You have to be able to create a group of people

Every person that could participate in the training should be added to this group. The gameplan will be made latter on based on this groups. After a group is made there a no people in it. The people will be added later on.

### Future Ideas

A group should have a field to choose a sport.

## REQ02: You have to be able to create a Person for the group

In the group there should be a option to create a new Player. Every Player has to have a name and a skillset. These skillsets will be needed for balanced teams in a gameplan. There should also be the option to tag a player who can only play goalkeeper. Optionaly you can add a Photo.

### Future Ideas

Different skillsets for different sports

## REQ03: You have to be able to create a Gameplan

First you have to choose the people of the group that are actually participating in this gameplan.

Then you should choose following settings: 
    - How many Teams
    - How many Player for each team (exc. Goalkeeper) *
    - How long should 1 game last (in min.)
    - How long should all the games last (in min.)
    - How much time in between two games (in min.)
There also should be a button to take the settings from the last game.

Now the software should automaticly create teams that are somewhat balanced and also create a gameplan.


*   if teams * players a. team < as participating players = error
    if teams * players a. team > as participating players = message
