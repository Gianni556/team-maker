# Team Maker

This software should help to create teams for teamsport like football volleyball and co. 

## The Problem

In winter me and my friends rent a indoor court for football. And every year we have the same problem: who makes the teams. Our time in the court is very limited so we have to have teams before we play. And every time it was a pain in the ass. We always need teams that are somewhat balanced. Because if one team was to dominant no one had fun. We "solved" this by having each week a new person making the teams. But this was never a real solution.

## The Solution

I will try to build a software were you can enter each player with there skillset for the givin sport. After that you should be able to make a Gameplan: The software creates as many teams as you like which should be somewhat balanced and makes a gameplan where this teams play against each other as often as it works out in a defined time.

## My focus

I will be focusing on my personal usecase for this software which means indoor football with 3 teams each having 5 on field player (inc. goalie) with 8min games and total playtime of 1h and 45min.
Later on i can implement more stuff and games and setting.
